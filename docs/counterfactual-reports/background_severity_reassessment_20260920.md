# Background consistency：主体干扰效应量再评估

2026-09-20，针对用户确认的“糊化主体、保留背景”重新检查证据。
本文件是已公开测试结果上的描述性复核，不是新的独立测试、不修改冻结门槛，
不更换主方法、不按分数筛选样本。原始[独立报告](background_holdout_20260920.md)和评分保留。

当前证据支持 repair 的平均稳定性与自然偏好表现改善，但不足以据此将
“origin 严重受主体干扰”作为已证明的结论。18 项原协议门槛通过是协议内的验收结果，
不能替代缺陷实际严重程度的判断。

## 扰动范围与绝对效应

188 条基底中，构造前景掩码面积的中位数只有画面的 5.50%，平均为 10.62%。
其中 82 条的平均掩码面积不足 5%。这些是自动掩码面积，不是人工主体面积真值。
全片采用同样的糊化操作，也保留了主体的运动和粗略外形；它未必是强烈的时序干扰。

| 构造掩码平均面积 | 条数 | origin 完整糊化平均绝对变化 | repair 平均绝对变化 |
| --- | ---: | ---: | ---: |
| < 5% | 82 | 0.008503 | 0.002617 |
| 5%–15% | 56 | 0.019297 | 0.007047 |
| 15%–30% | 33 | 0.020223 | 0.013577 |
| ≥ 30% | 17 | 0.035751 | 0.012262 |

分层是看完原测试后新增的描述，不作为新的主子集。面积与效应的关联不能单独证明因果。
全部 188 条的 origin 平均绝对变化为 0.016240，中位数 0.010227；只有 8 条超过 0.05。
repair 均值为 0.006733，但中大面积组仍有明显残余响应。
相对改善 58.54% 不能单独证明原缺陷很严重。

## 排序是否受到影响

从原有 1,560 对 background 测试偏好中，固定取“两侧视频均构造成功”的全部配对，
得到 71 对、21 个 source prompt。没有按原始分差、是否翻转或模型胜负筛选。
比较两个视频都保持原样和两个视频都完整糊化主体后的评分顺序；严格反转要求
干预前后的有符号分差乘积小于 0，平局变化另外计数。

| 方法 | 严格排序反转 | 反转率 | 95% prompt 聚类区间 | 干预前/后符合原人工偏好的对数 |
| --- | ---: | ---: | --- | ---: |
| origin | 11 / 71 | 15.49% | [6.06%, 26.47%] | 42 / 42 |
| repair | 5 / 71 | 7.04% | [2.25%, 12.86%] | 44 / 39 |

反转率缩减的配对 95% 区间为 **[−1.39, +18.07] 个百分点**，跨零。
在这个小子集中，repair 的五次反转均从正确变为错误；origin 的正确数整体没有变化。
这些结果没有推翻全部自然集上的提升，但也不支持“干预后偏好判别普遍改善”。
Bootstrap 按 source prompt 分组，10,000 次，seed 20260920。

## 对后续实验的含义

若继续把主体干扰作为主要机制，需要另立协议：先按画面内容及主体面积固定一批
主体明显的视频，再统一测试多档 Gaussian 强度、全片糊化与清晰/糊化交替的时序干预，
逐档验证背景像素保持不变，同时报告绝对变化、排序反转及 repair 残余响应。
新的选材与强度规则必须先固定，不因 origin 分差较小而反复换样本或只呈现强例。
已有测试不再作为新的未见验证集。

该新增实验尚未预注册或运行。若 origin 在合理强度下仍稳定，应接受
此类主体干扰并不严重，将 background 定位为改进证据或补充实验。
