# Background：独立定位失败原因与表示层消融

本诊断读取已经完成的 680 条原生 background 开发视频和六条构造可用视频的缓存结果，
没有重新拟合参数、运行测试集或更换默认方法。完整主实验见
[扩展构造后的定位修复](background_caption_localizer_20260920.md)。

## 空掩码来自哪一环

对 COCO80 + Caption v2 保存的逐帧轨迹进行互斥分解，并核验每条视频的计数与原记录一致：

| 13,770 帧的最终状态 | 帧数 |
|---|---:|
| 原 COCO80 已有非空掩码 | 3,474 |
| Caption 候选框经 MobileSAM 得到非空掩码 | 4,848 |
| GRiT 没有区域描述候选 | 744 |
| 只有场景或无法识别的名词头 | 3,592 |
| 物体候选框不满足冻结的面积条件 | 1,112 |
| 有合格提示框，但 MobileSAM 输出全空 | 0 |

后三类共 5,448 空帧，与自然评估统计严格一致；84 条视频全程为空。
面积条件为框占画面 1%–60%，不是把评分掩码凑成 20%。1,112 帧中，324 帧只有小于 1% 的框，
742 帧只有大于 60% 的框，46 帧两者都有。这里不判断所有被过滤框是否语义正确，
也不把“没有候选”解释为原片没有主体。

在建塔楼 `v_5b21df6d8c834540581f` 的 33 帧中，29 帧没有描述候选；另外 4 帧只出现模型
称为“鸟”或“交通灯”的小框，面积约 0.03%–0.27%，没有塔楼框。
因此其全空不是 MobileSAM 得到正确塔楼提示后分割失败；继续调整 SAM 边缘或描述解析不能
补出这段记录中未提供的主体候选。保留此失败，不降低面积门槛把这些小框当作塔楼。

代码：`scripts/counterfactual/diagnose_background_caption_coverage.py`。
产物：`output/background-repair/background-caption-coverage-diagnosis-20260920/`，包括完整逐视频
`diagnosis.json` 与 `box_eligibility_breakdown.json`。脚本不读取评分数值或偏好标签。
这只是模型输出覆盖诊断，不是人工分割准确率。

## 稳定性来自哪里

利用冻结评分网格进行表示与时间聚合的消融。所有 patch 对照都使用现有固定增益 1.75，
没有用这次标签重调分数范围。自然评估覆盖全部 1,020 对开发偏好、34 个 prompt；
干预列仅覆盖第五批六条已复核视频，不能外推为全体候选结论。

| 表示 / 聚合 | 自然偏好准确率 | 六条全片主体糊化 MAE |
|---|---:|---:|
| 原 CLS / 原官方聚合 | 52.35% | 0.010967 |
| 原 CLS / 全帧对聚合 | 52.55% | 0.010972 |
| 全图 patch / 原官方聚合 | 58.24% | 0.003637 |
| 全图 patch / 全帧对聚合 | 57.84% | 0.003405 |
| 现有 frozen19 repair | 57.84% | 0.003419 |
| COCO80 repair | 57.94% | 0.003252 |
| COCO80 + Caption v2 repair | 56.67% | 0.003002 |

在当前范围内，换用 patch 表示已有明显作用；只改 CLS 的时间聚合几乎不改变这两个结果。
全图 patch 不排除任何主体，仍能获得接近现有 repair 的稳定性；所以不能把全部稳定性改善
归功于正确的主体分离。全图 patch / 全帧对相对现有 repair 的自然准确率差为 0，配对
95% prompt 聚类区间为 [−0.686,+0.686] pp；相同平均准确率也不证明逐对预测完全相同。

这些是**开发集上的解释性消融**，没有据此改选最高分方法或替换默认修复。
它们仍不能满足 origin MAE ≥0.10 的目标，也不能替代剩余构造审核及定位语义验证。
后续新增构造输入沿用原判定标准，不能因本消融的分数选材。

代码：`scripts/counterfactual/analyze_background_localizer_ablation.py`。
完整方法对齐、干净像素对齐、分数哈希和偏好文件哈希在运行中核验；输出为
`output/background-repair/background-localizer-ablation-dev-v2-20260920/statistics.json`。
初版较少对照保留在 `background-localizer-ablation-dev-20260920/`，同目录保存当时分析源码。
受影响统计与校准算法检查为 **15 passed**。
