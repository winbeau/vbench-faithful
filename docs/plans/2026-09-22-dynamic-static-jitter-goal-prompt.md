## 1. 最终目标

对官方原视频叠加小幅、高频、零均值的局部空间往返位移，原有主体、场景与
原生运动过程保留。不声称逐像素几何完全不变：纹理位置抖动正是新增的干预。
检验原始 Dynamic Degree 是否因像素震颤而发生错误变化，并使 Repair 在这些
语义和实际运动未改变的编辑下基本不变，同时维持对原生真实运动的有效响应。

当前主合同是 `|S_cf − S_base| ≤ ε`，不是只要降分就算通过：
对原本有运动的视频，显著降分也可能表示 Repair 抑制了真实运动。
若官方原视频本身静止或低运动，可另外分析不抬分，但不得将整个数据集假定为静态。

## 2. 数据与构造

- 使用 VBench 1.0 官方 sampled videos；Dynamic Degree 的实际媒体目录为各生成器
  `subject_consistency/`。按官方原文件、源 SHA256 和源视频身份建立可追溯映射。
- 保留现有 metadata-only 分组选择作为开发/留出来源：开发 32 个源、8 个 prompt；
  预留测试 120 个源、30 个 prompt。尚未在新协议下评分的留出数据不得用于调参。
  它们曾参与 E0，故只称新干预协议的分组留出，不能称从未使用过的自然视频集。
- 不抽帧重复、不合成对象平移、不用生成模型造视频、不裁剪内容、不统一缩放构造
  分辨率、不调整基底亮度、不删换帧、不改变原有 FPS/时间戳，不替换原生运动过程。
- 逐帧对当前原始帧仅重采样一次：`I'_t(x)=I_t(x+a_t u(x))`。空间位移场平滑、
  空间均值为零、边界衰减到零；时间系数快速交替且均值为零。不累积变形，不加
  RGB 噪声、不改亮度，不把所有像素统一平移。保存位移场、边界/幅度/雅可比检查。
- 五视频 pilot 按 metadata 选前五个不同 dev prompt，生成器轮换 LaVie、ModelScope、
  VideoCrafter、LaVie、ModelScope；全部官方原生 MP4，不按分数挑选。构造 1/2/4
  原生像素、两个固定种子，加原片与零编辑 control，共 40 条候选。主展示固定
  2 px / seed 1701，六种组合全部报告；使用原 CoTracker2 dev-v4，不针对五条调参。
  配置：`construction.local-texture-dev5-v1.json`；清单：`sources.local-texture-dev5-v1.jsonl`。
- 源原文件不改写。MP4 原文件直接评分；若官方源为 GIF，而锁定上游仅支持 MP4，
  必须单列格式适配，逐帧保留全部内容与时序，验证解码像素及时间戳一致；不得将
  格式适配悄悄当成新视频内容。无法精确保留时明确拒收/待处理。
- 另提供同编码、零干预 control，以区分编码差异和扰动效应；主表仍明确给出
  原视频 → 干预视频，编码控制单列，不能把重编码 control 冒充原始文件。
- 检查帧数、尺寸、每帧时间戳、时长、实际扰动、裁切和结构保留；保存可复现
  参数及编码前后哈希。结构毁坏、过曝等拒收不能记为合法不变性测试。

## 3. Repair 路线与防退化

保留“本地预训练点跟踪 + 对应关系/可靠性算法”的候选路线：
当前视频 → 固定采样/网格 → 模型轨迹 → 双向与局部结构核验 →
固定时空分母的有效运动量。模型、预处理、可靠性和噪声容限只在开发集比较。

评分器仅输入当前视频，不读取配对原片、干预标签、随机种子、真值掩码或构造参数。
合法静止证据可以记零；证据不足必须显式标记，不能伪装成成功零分。
不能用恒零、整体缩放、丢弃全部受扰帧或大幅压低原生运动来获得稳定性。

真实运动响应在官方原生视频上检查，并对照可用的本维度人类偏好。
不再启动合成运动阶梯。已生成的旧阶梯只保留作历史算法诊断，不作为新验收依据。

## 4. 冻结与验收

旧合成阶梯的 R、ε 和排序门槛不适用于新主实验，禁止直接沿用或声称已经通过。
先完成官方原视频开发预览，再依据原生运动分数尺度和输入质量明确数值容差、
运动响应与覆盖门槛，写入版本化协议；独立测试前冻结，测试后不得调阈值。

必须共同核验：合法扰动、逐族逐强度的 Repair 绝对变化小、原生运动响应不坍缩、
有效评分覆盖、至少 100 个合格源的独立分组验证。构造拒收、评分失败、证据不足、
未运行、负结果分别记录，不能通过删掉高分差样本获得通过。
区间按源/prompt 分组，不能将同源种子和强度视为独立样本。

Origin 使用锁定上游 `fd18b3d055cb0fc6f066ca90fe2c3c8cbb698490` 的真实布尔分数，
报告 0→1、1→0、总翻转率以及不变项。基底已为 1 时存在饱和，不能强求每条均变；
连续光流诊断独立报告，不冒充官方最终分数。Repair 保持有物理单位的连续值，
两后端不直接比较不同量纲的差值。若 Origin 没有被干扰，应如实报告，不能挑例造结论。
