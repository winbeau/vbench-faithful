## 0. 最新目标契约：两种能力必须同时成立

**实现仅输入待测视频、输出连续运动强度的 Dynamic Degree Repair：对官方原片
上固定 8px 的内部纹理快速局部往返抖动不敏感，同时能识别实际存在的运动、
区分真实运动强弱，并保留物体、镜头、关节、周期及细小运动的响应。**
最终目标是改善对可见真实运动的测量；降低某一个 CF 均分只是诊断结果。

设 `V` 是官方完整原视频，`J(V)` 是其固定 8px 干预。期望
`R(J(V)) ≈ R(V)`，且在经过视觉核验/本维度标注的可比自然视频对中，
真实运动更强的视频应得到更高连续分。以下是**验收分组**，不将分组标签输入评分器：

| 可见运动情况 | 原片应有表现 | 加入同样 8px 抖动后应有表现 |
|---|---|---|
| 真正静止或低运动 | 低运动强度 | 仍低，不被局部纹理位移抬高；合理纠错降分可接受 |
| 持续物体位移或镜头运动 | 识别可见位移，保留运动强弱差异 | 真实运动仍被识别，强度基本保持 |
| 关节、旋转或真实周期运动 | 计算实际运动，往返本身不能被判为伪运动 | 不因带有抖动而把真实往返运动一并删除 |
| 小物体或小幅真实运动 | 不因空间占比小而漏掉或填零 | 抑制纹理干扰，同时保持小尺度运动响应 |

静止/运动分组必须看实际视频；不能拿 `Origin=0`、低光流或 prompt 的动词当真值。
同一画面序列不能保证唯一识别物理成因，因此结论限定在明确审核的构造和可见
运动范围，不承诺识别任意振动，也不以此回避已经确认适合的 8px 反事实。

### 固定条件与完成标准

1. **数据和 Origin 不变。**主实验仍是 32 个官方 VBench 1.0 MP4 / 8 prompt，
   每源原片、编码控制、两个固定种子，共 128 输入；保留全部构造质量标记。
   原片不静态化、不改为自生成视频；不降低 8px、不以 RGB 噪声替换位移。
   Origin 始终为原版 VBench 单视频二值判断及批量动态比例。
2. **抖动不变性主门槛不变。**先组内平均种子，再对 32 源等权平均；使用
   `Δ_m = mean(S_m(CF)) − mean(S_m(base))`，要求
   `Δ_Repair ≤ 0.10 × Δ_Origin`（仅当 `Δ_Origin > 0`）。当前 Origin
   涨幅为 0.187500，因此允许 Repair 平均涨幅至多 **0.018750**。
   **0.579409 只是当前 Repair 原片均值 0.560659 保持时的对应 CF 上限，
   不是所有未来方法必须拟合到的绝对分数目标。**
3. **真实运动响应同等必要。**需同时证明：自然运动/低运动可区分；在可比
   自然视频对中分数随真实运动强弱正确排序；真实运动视频加入抖动后不被
   系统性压成静止。用实际视频核验和 Dynamic Degree 自己的标注验证，
   包含上述运动类型及已知列车漏运动反例。具体统计与冻结要求见 §5。
4. **不能靠错误抵消通过。**主统计仍是用户指定的有符号批量涨幅，不改成
   MAE 或逐条 10% 门槛；但必须另报真实运动组/低运动组的有符号与绝对变化、
   严重降分和缺失。如果批量小变化来自把运动视频一起压低，真实运动门槛失败。
5. **尺度与算法分开。**当前运动量定义下继续使用冻结的
   `R=I/(I+0.12684953311437752)`，同时保存未映射强度 `I`。
   不通过重拟合尺度、加偏置、饱和剪裁或整体缩分达标。“均分接近/略高于
   Origin”不能代替真实运动正确性，也不要求逐片追随 Origin 的错误判断。
   若以后更换了原始强度定义，须另立版本、在不读取评测 CF 分差的自然开发
   数据上校准，并冻结后完整重评；不得把事后新尺度冒充本次可比结果。
6. **完成是联合通过。**完整覆盖、抖动不变性、真实运动敏感性及冻结后的
   独立验证都满足，才可标记 goal complete。`95 条原片分数不变`只代表未改变
   旧输出，不证明旧输出识别了真实运动；`0.68304→0.68147`也不构成修复成功。

方法不锁死在 CoTracker3/SAM 或现有残余分解上。下一版应围绕“哪些证据支持
真实运动，哪些只支持局部纹理往返”设计；更换模型、叠加门槛或平滑本身都不是
成功标准。原有模型/算法作为可复现对照，历史负结果和全部未完成项保留。
下面的历史设计不构成必须继续沿用同一方法的约束；当前验收以本节及 §5 为准。

[单视频评分](../../scripts/counterfactual/score_mp4_dev32.py)、
[残余往返分解](../../metrics/dynamic-degree/src/dynamic_degree/residual_reversal.py)、
[连续强度](../../metrics/dynamic-degree/src/dynamic_degree/motion_intensity.py)和
[冻结尺度](../../metrics/dynamic-degree/src/dynamic_degree/intensity_scale.py)。

- 残余往返候选从 0.560659 涨到 0.681470，涨幅为 Origin 的 64.43%；
  最新较大区域支持消融为 0.560659→0.678265，涨幅比例仍有 62.72%。

- 95 条自然原片保分没有纠正已知的运动漏检，也未证明高/低运动区分、强弱
  排序或真实周期运动响应；这一半目标仍未完成。

### 历史五源失败（不是当前实现或当前评分覆盖）

以下保留旧 [CoTracker2 路径](../../packages/audit-models/src/vbench_audit_models/point_tracker.py)
与[轨迹评分](../../metrics/dynamic-degree/src/dynamic_degree/trajectory.py)的诊断结论。

1. **运动定义问题。** 当前方法在对应关系通过后累加相邻帧路径长度。真实跟踪到
   抖动并不等于识别了真实运动；局部来回位移同样贡献正路径长度。只换更准确的
   tracker 也可能更准确地追随干扰。4px 列车 `0 → 0.009956/0.010426` 已暴露此问题。
2. **证据获取问题。** 当时网格只从第一帧发起，整段末帧反向跟踪检验循环；刚性
   灰度 patch 匹配对局部形变敏感。首末帧遮挡、漂移可能损失整段证据。雪地自行车
   原片覆盖仅 33.29%；8px 列车覆盖降至 49.54%/43.19%。不能只处理扰动而忽略
   原片已无法评分的问题。
3. **该轮结论是失败，不是稳定。** 十条用户接受干预的 Origin 动态比例为
   `40% → 80%`；Repair 仅 `4/10` 有效配对。其余六条 null 不是零分，也不是
   不变性成功。五源小样本只支持开发诊断，不代表总体实验结论。

### 最初数据流（以下已做开发对照，不能再当作充分设计）

```text
单个视频 RGB + 原生时间戳
  → 固定时空采样，多起点、重叠短窗的 CoTracker2 轨迹
  → 局部双向循环与结构匹配：恢复/核验对应关系，单独输出置信度
  → 多时间间隔轨迹分解 + 多尺度区域结构支持
  → 保留真实运动分量，抑制缺少结构支持的局部往返残差
  → 固定时空统计单位的运动量 + 覆盖率 + 分量诊断
```

### A. 先修可靠性，而不是降低弃权门槛

首先复用已有本地 CoTracker2 权重，不立即换大模型或下载新权重。增加时间中部的
query grid 和重叠短窗，每个局部窗独立做正反跟踪；允许遮挡后的新可见区域重新
获取轨迹，避免所有点都受第一帧和最后一帧支配。

对应关系检验从单一刚性灰度 patch 扩展到多尺度、允许局部几何变化的结构匹配；
匹配置信度只回答“点是否可靠”，**不能充当抖动分类器**。具体匹配器、窗口和
阈值属于待比较的开发候选，不宣称现有 CoTracker2 wrapper 已提供额外特征接口。

先固定统计网格/时窗，再把多条重叠轨迹合并到同一统计单位，不能通过重复 query
增大某区域权重。失败处先重定位或做可核验的区域运动估计；仍不足则显式缺失并
计验收失败，不填零、不删除该视频，也不能仅靠降低现有 60% 门槛宣称覆盖改善。

### B. 再区分运动成分，而不是抹掉所有高频

对可靠轨迹使用多个真实时间间隔、多个起始相位；8 FPS 开发片至少比较
1/2/3/4 帧间隔（125/250/375/500 ms），不能只取偶数帧或专门滤除 4 Hz。
全部原始时间相位须参与诊断；更长/不同 FPS 视频按秒定义窗口，记录实际采样。

设局部轨迹 `q_i(t) = b_i(t) + r_i(t)`：`b` 为鲁棒估计的持续变化分量，`r` 为
短时残差。时间分解只提出“可能的往返分量”，不能直接断言 `r` 都是噪声。
结合以下互补证据，只对缺少结构支持的局部往返残差降权：

- 时间上是否反复反向、局限于较小邻域；不能仅因整段净位移小就删除。
- 是否有同一可见区域内多个点的协调运动、可解释的局部平移/仿射变化，且在多个
  空间尺度上有支持；不能要求不同物体、不同肢体或整个画面方向一致。
- 结构支持来自视频自身的外观/轨迹，不读取建库位移场、8px 标签或配对原片。
  小物体和非刚性区域需单列诊断，不能用“大区域才算运动”的规则偷换目标。

候选组合写作 `d_i(t) = Δb_i(t) + g_i(t) Δr_i(t)`，`g∈[0,1]` 表示残差的
区域结构支持。先合成向量再取长度，避免把两部分长度相加造成重复计数。
`g=1` 保留该点原运动；只有时间与结构证据同时支持干扰解释时才抑制残差。
挥手、翅膀拍动等真实周期运动不能仅因高频而被去除；镜头运动默认保留，不将
“真实运动”擅自缩窄为前景物体相对背景的位移。

最后按固定时空统计单位累计运动量，除以短边尺度和实际持续时间，保持可解释的
“短边长度/秒”。缺失部分如何估计、置信界如何传播是实现时必须解决的项目，
不能把缺失运动隐含填零后仍称完整分数。空间/时间尺度与门槛必须在开发阶段锁定。

**这是待检验的设计，不是已证明有效的公式。** 平滑位移场自身也可能有局部结构
一致性，真实细小周期运动也可能与干扰相似。仅凭 RGB，若两种成因产生相同帧序列，
就不存在能保证识别物理成因的通用判据。本工作检验明确范围内的可见运动与鲁棒性，
不承诺识别一切振动，更不能用这一局限否决已认可的 8px 反事实。

这说明对应恢复与运动定义两部分均须继续改进；该轮结束时 DINO 尚未接入。
随后的独立描述子对照见本节开头及实验报告，仍未达到要求，不以新方法名称
绕过覆盖/运动响应门槛。

## 4. 什么算合法改进，什么不算

允许：独立预训练视觉跟踪 + 通用运动/对应关系算法；只在开发集调整参数；在
数据支持时扩展视频自身的结构特征。先比较算法增量，再决定是否需要新模型。

禁止：读取原片与干预配对、seed、位移场、文件名暗码；把 8px 写成评分噪声阈值；
只跳过一帧以消掉交替相位；把所有高频/周期运动归零；整体缩分使绝对差变小；
把 null 当零或把评分失败从分母删除；看过留出结果后再调参数、换源或弱化构造。

必须比较：Origin、当前连续候选、无抑制运动量、新候选完整方法，以及对应的
仅时间分解/仅结构核验等必要消融。旧 dev-v4 与二值头只作历史对照，不混成
当前主结果。时间滤波/偶数帧捷径/恒零可以作**失败对照**，不能晋升 Repair。
每个候选同时给出原片运动响应、干预差值和证据覆盖，不能只报成功案例。

## 5. 验收设计：三个门槛共同成立

### 开发与冻结

五源 × 两种子是已看过的开发回归集：目标是五个原片与十条干预均有有效评分，
列车、长颈鹿误增受抑制，雪地自行车能正常处理，同时自行车与马的真实运动保留。
十条必须全报；通过它们只允许进入下一阶段，不等于独立验证成功。

开发扩展保持 32 源 / 8 prompt；预留 120 源 / 30 prompt 不变。用户已明确授权
替换原开发清单中缺时长的 8 条 GIF，当前清单为
`sources.local-texture-dev32-mp4-v1.jsonl`：保留 24 条 MP4，再按固定 UID 哈希和
生成器轮转补选 8 条官方开发 MP4，不参考评分，不使用测试源。各源的 base/CF
作为一组、等权进入均值；不是 32 个 prompt。多个干预种子先在组内平均，再
对 32 组平均，同时分别附报各种子；编码控制不重复加入均值。不得根据评分
挑选种子或剔除失败组。32 组完整评分前不以有效子集均值冒充 32 组结果。
后者是“新干预协议的 prompt 组留出”，视频曾参与自然 E0，不能称全新自然样本。
保持主干预 8px；未看过样本的语义审核不得根据评分差选择。主构造不改成 RGB
噪声、静态帧复制或生成视频。新种子/不同相位等泛化检查另列，不能替换主构造。

在官方原视频中另检查持续位移、镜头移动、关节/周期运动、细小真实运动与自然
低运动片段；具体类别由视频审核确定，不凭 prompt 推断。原片与本维度人类偏好
共同约束运动响应；不复用 Subject 的人类偏好，也不恢复旧合成运动阶梯作主证据。

### 联合门槛（开发预案，数值需在留出前冻结）

1. **覆盖。** 五源开发回归要求十条干预及五原片全有有效分数；正式留出至少
   100 个已审核源，总体及预先定义的关键分层有效配对率 ≥95%。所有缺失仍留在
   分母；有效视频比例与视频内部证据覆盖分别报告，检查 CF 是否系统性丢失运动点。
2. **不变性（用户更新：32 组平均分）。** 在同一固定、可比评分口径下，分别
   报告 Origin/Repair 的 base 均分、CF 均分与有符号涨幅 `Δ_m`，主门槛为
   `Δ_Repair ≤ 0.10 × Δ_Origin`。仅当 `Δ_Origin>0` 时解释涨幅比例；否则
   该批未显示 Origin 虚高，比例不适用，不自动判通过。单条误增、降分、极值、
   缺失及 prompt 聚类区间照报，但不另要求每条均小于 10%。旧 `ε=0.05R`、
   “90% 逐对通过”和 MAE 区间上界门槛保留为历史预案，不再并列为本次主验收。
3. **运动敏感性。** 自然高/低运动区分及真实周期运动组须保留；结合 Dynamic
   自己的人类偏好做配对比较，既有开发预案的非劣容限为 2 个百分点，
   `CPA_Repair − CPA_Origin` 的 95% CI 下界须 ≥−0.02；这是待在留出前冻结
   的方案参数，不称为用户新指定的数值，也不把“与差基线非劣”当成充分证据。
   必须同时提供以下正向证据：

   - 在独立于分数审核的运动/低运动自然视频对及可比强弱运动对上，正确方向
     的评分差和排序表现；报告平局、错误和区间，不得用全相等分数通过。
   - 持续位移、镜头、关节/周期、小幅运动分别检验；已知列车漏运动反例要
     给出实际对应/运动响应的核验，不只保持原来的错误低分。
   - 分别报告每类原片→8px 的均值差、绝对变化和严重降分，不能让真实运动
     被系统性压低后再与静态误增相抵消。静态合理降分不等同于运动视频降分。
   - 自然对构造、运动类别/强弱标注、最低有意义差异及每类保留容限须在
     不看留出结果的开发阶段定好并冻结。当前尚未完成这些标注/参数，记为
     **PENDING / NOT RUN**；不能以“95 条分数未变”填补或默认通过。

这一扩展把“真实运动关注”落实为主动识别和强弱排序，不仅是对旧分数的保留。
单项通过不是完成；缺标注、缺运动类型、区间无法支撑结论均明确保留未完成。

10% 和 32 组批量均分来自用户在五源结果之后的新要求，是开发期验收变更，
不是事先冻结的独立验证。32 组 base/8px CF 及编码对照现已全量完成，连续
Repair 从同一模型缓存重算；没有把二值化结果继续作为 Repair 主结果。
当前 63 条自然数据已完成数值尺度校准，但尚未完成真实运动语义验收；
二者不能混写为“未校准”或“自然运动已验证”。
原有覆盖与真实运动保留要求不因放宽涨幅而取消。评分尺度、运动分组、内部
证据门槛及区间计算规则仍须冻结；未冻结不启动正式留出，不沿用 Subject 的阈值。

Origin 保持上游 `fd18b3d055cb0fc6f066ca90fe2c3c8cbb698490`：报告动态比例、
0→1/1→0 及配对 CI，不把动态比例叫准确率。Repair 是连续运动量，不能直接
将两个量纲的 Δ 大小当效果优劣。区间按 prompt 聚类，种子不作为独立视频。
因此当前五源 CoTracker3 的 `0.034739` 仍是条件运动诊断量，不能直接除以旧
五源 Origin 的 `0.40` 就宣称通过，更不能把旧五源的 `0.04` 固定为新 32 组门槛。
当前尺度映射已独立于这批 8px 分差固定，继续比较同一定义时保持不变，
不能事后缩分制造达标。更换运动量定义时按 §0 的显式新版本规则处理。
