# 四维消融、小模型与泛化评估

已完成同数据的 0.6B 四维训练、0.6B/8B 的 base 与 SFT 对照、接口消融、Scene 证据消融，以及独立于旧 60 对别名字典的新表达测试。共 **950 条输入、4,584 次模型预测**，无计划项缺失。仅使用固定步数 final，未按新测试选 checkpoint。

**结论：目前不能声称四维 Repair 已获得普遍泛化保证。** Spatial 8B 的工程契约表现最好；Action 的新表达到 K400 类别映射仍不足；Scene 的长文本明显失败；Objects 的时序过滤降低误报，但也损失正例。本轮发现并修复了 Action 接口越界改写问题，修复后结果明确标为后验回归。

## 2. 抗捷径指标与长度泛化

**WG-CC = 所有“维度 × 变换”组中最低的双端正确率**。原句与改写各自都符合目标才成功；语义变了必须输出新目标。缺失、无效输出和不恰当的 other/空答案计失败。恒定空/insufficient、复制 canonical 的 Oracle 得分均为 **0**，真正 Oracle 为 **1**。

所有原冻结系统的全维 WG-CC 均为 **0**；SFT 的共同最低组是新 Action 改写。这个结果揭示旧封闭词典成功不能替代泛化结论。每组 24 家族，Wilson 名义同时下界作 24 组校正；即便满分，下界最多 0.7451。共享作者模板使独立性只是近似，不是人口总体可靠性保证。定义、来源及边界见 [method.md](method.md)。

## 3. Action 接口越界问题：已修补，单列后验回归

推理与评分默认 `--action-interface repair-v2.1`，`repair-v2` 可精确复现旧版本，`legacy-model` 可关闭此接口。下表是**同一批已见输出上的后验回放，不作为新的盲测泛化证据**：

## 5. 固定视频缓存的组件消融

这部分复用已见的回归集，不能当作新增盲测。

- **Spatial**：同一 106 个原方向成立的视频，只有冠词归一化时原始/镜像为 0.5597/0.5597；加入正确主体配对但仍无符号时为 0.4442/0.4442；加入方向符号后为 **0.4442/0**。方向修复来自有符号几何，不是单纯换解析器。完整各阶段与反向集合见 [spatial-components.csv](spatial-components.csv)。
- **Action**：旧模型原句/同义分数为 0.8650/0.3783；只归一化输出为 0.8650/0.7700；完整封闭契约为 0.8892/0.8892。这个收益主要来自已有词典的接口保障，不能推广到新改写。见 [action-components.csv](action-components.csv)。
- **Objects**：相邻标签与相邻框确认都把 275 个模型复核不可见端点中的正分残留从 29 降到 15，但全部明确阴性的端点仍为 246。计入正例保留、且弃权不得充当正确阴性后，模型可见性标注集的原始帧均衡正确率为 **78.36% → 77.64% → 77.37%**；变换后为 **50.52% → 49.59% → 49.59%**。因此不能声称总体正确性提升。这是既有模型标签上的描述性再汇总，无新增人工视觉真值或 CI。见 [组件](objects-components.csv)、[正例保留](objects-retention.csv)、[均衡正确性](objects-balanced-correctness.csv)。

## 6. 架构、资源与验收

两种规模均为 dense Qwen3，三解析任务共享冻结底座并硬路由独立 LoRA，Scene 独立；r=16、alpha=32。层数/attention heads、参数量、结构图与来源见 [架构说明](method.md)。0.6B 单 LoRA 10.09M 参数，8B 为 43.65M，因此这是同配置规模/结构对照，并非等参数预算。

四任务使用与当前 8B 相同的数据 SHA、配置和固定 600/300/300/900 步。四个 0.6B 的 Trainer 时间共 2,527.39 秒；八个模型的底座冻结、adapter 更新、final 与最后 checkpoint 相等均通过。见 [训练记录](training.csv)。仅使用已确认的 RTX4090 GPU 5。

| 规模 | 实际预测 | GPU generation 秒 | 进程峰值分配 GiB |
| --- | --- | --- | --- |
| 0.6B | 2292 | 263.10 | 1.76 |
| 8B | 2292 | 304.81 | 16.86 |

以上时间不含加载/哈希校验，包含 base/SFT 的不同输出长度，不能解释为纯模型吞吐倍率；显存为本进程峰值 allocated。逐任务 SFT 批处理摊销延迟见 [latency.csv](latency.csv)，不等于单请求交互延迟。

验证：**226 passed**；全部新/改 CLI help、uv lock --check、git diff --check、完整推理分母与 SHA 检查通过。模型、数据、预测、错误样本、训练 checkpoint 留在忽略目录；Git 工作区仅保留实现、配置和聚合报告，未提交或推送。

进一步的强泛化结论还缺少四维独立人工金标、自然长提示词、多 seed 及其他模型家族/输出架构的对照。尤其需要重新构造与训练目标一致的 K400 类别映射数据，并在新的表达族盲测上验证；本轮不再用已看过的挑战集调权重、词典或阈值。
