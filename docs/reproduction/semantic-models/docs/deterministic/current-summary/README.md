# 四维实验当前结果汇总

当前结论：**Spatial 的方向判据已修复；Action 在既有同义契约覆盖域内稳定；Scene 在模型标注的 caption 证据上明显优于规则；Objects 减少孤立误报，但存在检出损失和持续误报。** 不能概括成“四维均已完全修复”，也不能把系统收益全部归于 LoRA。

本页合并 Spatial / Action / Objects repair-v2 与保持不变的 Scene 结果。统一主矩阵来自 `output/deterministic/matrix-objects-v2/`，共 **29,660 清单项、88,980 条三方案评分、81 个维度/方案/条件汇总**。所有模型均使用固定步数的 final checkpoint，不按 dev/test 选择 checkpoint。本次只整理已有结果，没有新训练、推理、API 或评分。

| Action | v9 | 605 / 67 | 300 | 模型动作解析＋既有 K400 同义词典与当前文本契约 |

## 3. 关键变换结果

箭头表示同一方案、同一配对样本的原始→变换。Objects 行表示不可见端点仍有正分的数量，越少越好，不是变换前后均分。

| 维度与条件 | 样本 | Origin | Repair-rule | Repair-model |
| --- | --- | --- | --- | --- |
| Spatial：框镜像，原检测几何仅支持原方向 | 106 视频 / 38 家族 | 0.5597→0.5597 | 0.4442→0 | 0.4442→0 |
| Action：动作同义改写，视频不变 | 1,200 视频 / 60 家族 | 0.8892→0 | 0.8892→0.8892 | 0.8892→0.8892 |
| Scene：场景同义改写，视频不变 | 200 视频 / 10 家族 | 0.3059→0.0541 | 0.3581→0.3581 | 0.6909→0.6947 |
| Objects：模型复核目标全帧不可见后仍有正分 | 275 视频 / 48 家族 | 29/275 | 15/275 | 15/275 |

### Spatial：方向响应达成，真实检测仍有误差

- 在 106 个原几何单向成立的视频上，Repair 的“原始／仅框镜像／仅换方向词／两者同步”为 **0.4442／0／0／0.4442**，106/106 符合四格趋势；Origin 四格均为 0.5597。下降至少 0.03 的是 102/106，不混同方向通过率。
- 在 98 个原几何只支持反方向的视频上，Repair 为 **0／0.3724／0.3724／0**，98/98 符合趋势。正确修复并不意味着所有视频镜像后一律降分。
- 真正镜像视频并重跑检测时，上述 106 个视频为 **0.4442→0.0094**，同步换方向词后为 **0.3919**；101/106 下降至少 0.03，但只有 40/106 同步恢复到原分±0.03。
- 实际后端实体集合匹配由 46/49 修至 49/49。方向收益来自共享确定性几何，原生模型输出未改变；几何分组不是人工视觉金标。

原方向成立子集的框镜像 Δ=−0.4442，95% 家族 CI=[−0.5253, −0.3492]。详见 [Spatial 报告](../spatial-repair-v2/README.md)。

### Action：已知同义表达稳定，泛化范围须明确

- **60/60** 同义类别对正确且一致，**1,200/1,200** 视频的原始/同义分数精确相同；Repair Δ=0，CI=[0,0]。Origin Δ=−0.88917，CI=[−0.92833, −0.84333]。
- 旧模型链路为 0.8650→0.3783，只有 25/60 类别对正确且一致；仅输出短语归一化为 0.8650→0.7700、51/60；完整接口为 0.88917→0.88917、60/60。
- 词典沿用首轮已存在的 60 对表达，没有按失败新增同义词。当前结果是**固定模型＋确定性接口**的收益，不能证明未见同义表达泛化。
- 类别替换后均分 0.00167；OOV `assembling furniture` 输出 other/0，但只有一个独立输入；已知＋未知动作保留已知项，总均分 0.44458，已知分量仍为 0.88917。

详见 [Action 报告](../action-repair-v2/README.md)。

### Scene：模型有明确的证据判断收益

同义均分基本稳定之外，补充比较同域 200 视频×16 captions 的 **3,200 对、10 来源家族**，以模型生成的 caption 标签判断 supported / not-supported 是否正确且一致：

| 指标 | Origin | Repair-rule | Repair-model |
| --- | ---: | ---: | ---: |
| 同义正确且一致率 | 0.26719 | 0.62438 | **0.92125** |
| 原始 caption 二分类准确率 | 0.57219 | 0.62438 | **0.92906** |
| test2 共同二分类准确率（432 项 / 5 来源块） | 0.81713 | 0.81713 | **0.96296** |

同义正确且一致率的模型 CI=[0.88438, 0.95563]；模型相对 Origin 的配对提升为 0.65406 [0.57281, 0.73375]。test2 全 492 项的模型三分类准确率为 0.82927，macro-F1=0.79337 [0.76210, 0.81956]；这与 432 项共同二分类是不同分母。

同义均分 Δ=+0.00375，CI=[−0.011875, 0.021875]，但逐视频±0.03 不变率只有 82%，不是逐项精确不变。正确且一致率也略低于复制原始模型判定的 0.92906。上述标签均不是独立人工金标，补充同义普查不是新盲测；不能将这些准确率改写成真实视频理解准确率。详见[原报告 Scene 结果](../../deterministic-experiments-report.md#scene同义收益与正确性边界)。

### Objects：误报减少，同时漏检增加

- 275 个模型复核不可见端点中，正分残留 **29→15**，减少 48.3%；正分帧 **158→118/4,400**。端点正分率差为 −0.05091，家族 CI=[−0.08392, −0.02244]。
- 过滤不足确认的检测会产生弃权。“无正分”由 246→260，但**全部明确阴性仍为 246**，不能声称新增 14 个已证实正确拒绝。
- 原始双方可见帧检出 **3,120/4,887→3,023/4,887（63.84%→61.86%）**；遮挡后双方仍可见帧检出 **38/1,024→19/1,024**。原始均分差 −0.02258 [−0.02659, −0.01907]，在 0.03 均分容差内仍不意味着无损。
- 相同 115 个旧正基例隔离移除视频，达到 0.03 降幅由 **114→106**；若要求两端无弃权，仅 **87/115**。该方法没有全面提升敏感性。
- 全计划 980 端点中，505 个完成模型复核、475 个几何不完整仍保留未知。重度目标遮挡覆盖率只有 0.64872；等面积重度背景对照只有 25/980，不能外推到全体。

**当前是带检出代价的孤立误报过滤，持续误报仍未解决。** 详见 [Objects 报告](../objects-repair-v2/README.md)。

## 4. 可支持的结论与材料

| 维度 | 当前可支持的结论 | 主要来源 | 仍不能声称 |
| --- | --- | --- | --- |
| Spatial | 检测证据中的有向几何满足镜像/方向词四格关系 | 实体序列化与确定性后端 | 真实检测完全等变、模型获得新视觉能力 |
| Action | 既有同义契约内类别与分数稳定 | 冻结词典和文本归一化接口 | 纯模型同义泛化、稳健开放集识别 |
| Scene | 对模型标注 caption 证据，模型优于规则/Origin | Scene 三标签模型 | 独立人工视觉正确率、长提示词泛化 |
| Objects | 一部分孤立正分转为弃权 | 相邻同名框确认 | 无损提升、全部正确拒绝、持续幻觉已修复 |

所有 CI 使用 2,000 次来源家族 bootstrap，seed=20260919。视频、帧、提示词对和来源家族的分母分别报告，不把重复帧当成独立来源。当前模型及修复已检查过这些实验，后续修复结果属于工程回归。

最近完整实现验收为 **219 项测试通过**。Objects 更新时其余 63,500 条评分逐字段不变，旧 Objects 38,220 条可用 legacy 模式重现。本次核对三个 v2 专项报告与最新总矩阵的数值逐项一致，并生成统一资料；没有重跑实验或修改评分。

- [summary.json](summary.json)：当前原始均分、Spatial 条件趋势、Action 消融、Scene 正确性、Objects 代价的完整统计。

- [matrix-scores.csv](matrix-scores.csv)：81 条当前全条件结果，带覆盖、弃权与差值 CI。
- [manifest.json](manifest.json)：本次汇总的输入和数据产物 SHA、版本与来源一致性记录。
