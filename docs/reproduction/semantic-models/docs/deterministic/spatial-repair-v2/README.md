# Spatial 方向修复 v2：已实现并完成缓存复算

上一轮只修文本接口，Repair 仍调用忽略方向符号的官方几何，确实没有完成方向修复。本版将 **Repair-rule / Repair-model 接入有符号主体—客体评分**，Origin 保留官方公式。复用 Spatial v8 固定 final、原始预测和同一 GRiT 缓存；没有重新训练、修改标签或按实验结果调阈值。协议见[实施计划](../../plans/13-spatial-direction-repair.md)。

## 实现

- 对象中心横坐标向右、纵坐标向下；left/right 判断主体中心小于/大于客体，above/below 判断主体纵坐标小于/大于客体。保留官方主轴严格占优与 IoU=0.1 重叠权重。
- 主体和客体分别匹配检测标签，两个不同实例才可配对；不会再把两个 A 当成 A+B。有效有序对取最大值，多实例可能同时支持正反方向，明确保留此类歧义。
- 文本端统一去开头 a/an/the，再用既有公共实体词表唯一逆映射；不删属性或猜测未知实体，不参考检测结果纠正目标。原始 JSON 保留。原提示词、反转提示词的实际后端集合匹配都从 **46/49 到 49/49**；这是序列化修复，模型原生输出未变。
- `score_matrix.py` 默认 `repair-v2`；`legacy-official` 重现首轮行为。`score_spatial_mirror.py` 共用新验收入口，不再另调官方无符号公式。

核心实现：[spatial_repair.py](../../../src/vbench_prompts_compile/spatial_repair.py)、[评分入口](../../../scripts/score_matrix.py)、[验收入口](../../../scripts/evaluate_spatial_repair.py)。

正确原方向子集配对 Δ=−0.4442，95% 家族 CI [−0.5253,−0.3492]；反方向子集 Δ=+0.3724 [0.2989,0.4471]。水平/垂直均通过，详见[视频趋势表](video-trends.md)。数值完全恢复按 1e−10 浮点容差验收。沿用 0.03 的幅度门槛时，分别为 102/106 与 90/98；其余原分较低，方向仍正确，不能称全部下降至少 0.03。

全量 980 视频中还有 64 个存在混合方向，712 个没有满足所需主轴的有效主体—客体方向证据；均未从全量均值移除。帧级有 12,381 个缺少至少一个目标、2,082 个多实例、564 个非所需主轴或主轴并列，另有上述 653 个唯一框方向明确帧。执行覆盖率 1 不意味着检测目标完整。**不能要求本来反向、双向或无目标的所有视频都统一掉分。**
