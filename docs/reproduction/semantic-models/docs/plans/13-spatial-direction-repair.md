# Spatial 有向评分修复 v2

用户已要求完成方向修复。本次修改 Repair 的确定性后端；Origin 继续回放冻结官方公式。复用现有 final adapter、980 个四方向视频及原始/镜像 GRiT 缓存，在新目录报告，不覆盖 matrix-v1 历史结果，不启动训练或 API。

## 实施前固定的规则

- 屏幕坐标 x 向右、y 向下。主体 A 相对客体 B：left 要求 Ax < Bx，right 要求 Ax > Bx，above 要求 Ay < By，below 要求 Ay > By。
- 保留官方主轴严格大于副轴和 IoU=0.1 的重叠权重；只在方向符号成立时给正分。
- Repair 仅配对分别匹配主体、客体的两个不同检测实例。按有效有序对的最大值评分；不把两个 A 当成 A+B。多实例可能同时支持正反关系，明确报告这种情况，不据此宣称每个样本都应下降。
- 文本侧去除开头 a/an/the，统一大小写与空白，再使用既有公共词表唯一逆映射；不删属性、不模糊猜测未知实体、不读检测结果纠正目标。保留模型原始 JSON。
- 16 帧分母、缺失记零及覆盖单列不变。坏框/不支持的关系不得产生正分。

## 验收

1. 四个方向的最小实例：原本成立 → 仅镜像为零 → 镜像并交换方向恢复；原本反向 → 镜像升分。Origin 四格不变。
2. 随机有效框、相交框、主轴并列、缺失目标、同类多实例、坏框、检测顺序、混合多关系、未知实体的回归。
3. 全部 980 视频保留，证据镜像四格分别报告。方向明确的检测框子集按原始几何统一选择，三方案用相同分母；这是几何代理，不是人工视觉真值。正向、反向、无法确定单列。
4. 视频镜像重跑 GRiT 的既有缓存独立报告，不保证检测器等变；不以证据镜像的数学正确性冒充视频识别准确率。
5. 消融区分文本序列化、主体/客体配对、有符号几何的作用；收益不能归于重新训练。
6. 原始和交换提示词的原生/后端匹配分别报告；输出 SHA、代码 SHA、家族 bootstrap（2,000 次，seed=20260919）及 Origin 逐项历史一致性。

代码默认使用 repair-v2；提供 legacy-official 模式重现 matrix-v1。完整 pytest、CLI help、lock check、diff check 后更新报告及验证记录。本次未获得新的 commit/push 指令，仅完成本地实现与验收。
