# S4：提示词长度泛化约束

状态：新增必需目标，待实施与验证；不是已经达到的性能承诺。本计划补充S1数据、S2编码和S3验收，训练配置与其冲突时以本长度预算要求为准。

## 1. 范围与分桶

覆盖极短、一句话、中长及超过200词的prompt，不承诺无限长度。第一阶段支持范围以实际token预算为界，并单独测试201–400词、401词以上样本。

英文prompt用固定的非空白串计数作为工程word_count，同时保存字符数及固定tokenizer的token数；这不是跨语言通用分词定义。非英文另按token数分层。不能将200词等同200 tokens。

| prompt词数 | 训练采样建议占比 | 重点 |
| --- | ---: | --- |
| 1–14 | 15% | 短语、省略、无显式关系/动作时不补造目标 |
| 15–49 | 20% | 常规一句话，约15词必须有覆盖 |
| 50–99 | 20% | 多句、修饰语与多个实体 |
| 100–200 | 25% | 长依存、多动作、多关系、场景与动作分离 |
| 201–400 | 20% | 超长prompt中的遗漏、指代、尾部目标 |
| 401及以上 | 独立压力/OOD桶 | 只纳入token预算可容纳样本，明确外推边界 |

占比为起始数据设计，不是已有数据统计或硬性最优比例；每任务分别核对，不靠重复少数长样本填满配额。缺桶则报告缺口，不称已覆盖。正式扩到401+词训练时，另留更长独立测试层并披露训练长度分布。

## 2. 数据构造与正确标签

- 在现有MovieGen、Flickr等原料上先统计各桶实际数量、token分位数、实体/关系/动作数量；来源与长度不能完全绑定。
- 增加同语义短版/长版家族用于一致性测试，所有版本与原始来源绑定同split。
- 不通过截断长prompt获得短标签样本：截断可能改变目标或指代。压缩改写必须重新审核完整性。
- 增加场景、动作或物体并非普遍“无关填充”：新增物体会改变Objects目标，新增动作/空间关系也要更新标签。只有经审核确实与当前维度无关的扩写才能复用target。
- 明确增删条件的对照样本，检查模型会随目标变化更新JSON，而非无条件维持原输出。
- 将关键对象/关系/动作/场景要求放在开头、中间、末尾；控制条件数量和难度，区分长度效应与组合复杂度。
- Scene对同一caption使用语义等价的长短prompt时标签应一致；改变场景条件时重新标注。
- 极短或无相关条件的输入必须先确定空数组、不足或不支持协议；不得凭常识补出关系或K400动作。没有明确场景要求的Scene样本在协议确定前隔离。
- 不因本计划自动授权teacher调用；自然原料不足可先手写工程样本，不能把工程模板当自然泛化证据。

## 3. 编码与长度预算

- token预算按系统指令、完整prompt、Scene caption、模板特殊token、完整输出及EOS一起计算，不能只统计prompt。
- 取消把512/1024作为统一固定上限的做法：先统计全序列长度，建议评估2048与4096配置，再按目标覆盖及48GB实测资源选定。
- 训练目标过长不得静默截掉；推理预留max_new_tokens并记录finish_reason。多三元组JSON可能比prompt更长。
- 输出被长度限制截断要记失败，不能只解析已生成部分并当成完整正确结果。
- 训练使用动态padding、长度分桶batch；每epoch仍混合各长度，避免按长度单向排序带来任务偏移。初版packing=False。
- 超预算样本进入明确overflow队列，报告每桶数量；不能删除201+词难例后宣称长度鲁棒。
- 若后续需要切块，须单独解决跨块指代、关系与去重并重新验收，不作为本轮默认fallback。
- GPU smoke包含每个主要长度桶，测长prompt对应的峰值显存和吞吐，而不只测最短fixture。

## 4. 独立评测设计

必须区分：

1. 混合长度训练后的各桶域内表现。
2. 同语义长短变体的判定一致性与正确性；稳定输出错误不算通过。
3. 固定语义复杂度的首/中/尾关键条件位置测试。
4. 未见长度区间外推，例如训练<=200词的对照模型在201–400词上测试；不能用已训练长度表现宣称外推能力。

| 任务 | 分桶指标 |
| --- | --- |
| Spatial | 有序三元组集合P/R/F1、完整正确率、方向错误、漏关系率 |
| Action | 类别映射与多动作完整率、无关动作误提取率 |
| Objects | 实体集合P/R/F1、漏对象率、幻觉对象率 |
| Scene | macro-F1、每类召回、混淆矩阵、长短一致率 |

共同报告schema有效率、截断率、失败/不支持率、样本与独立家族数、token分布、p50/p95时延。按来源家族bootstrap，不能把同源改写视作独立观测。

工程smoke至少每任务每个主要桶准备少量合法fixture，验证训练和推理不会丢失尾部；不设小样本准确率为研究结论。正式金标准建议每任务每桶至少100个独立家族，数据不足时报告CI与缺口，不用重复变体凑独立样本。

预注册候选门槛：控制复杂度后长桶相对短桶主指标非劣界3个百分点，报告差值CI；绝对质量门槛与不支持覆盖另行确定。该门槛是设计建议，需在看正式测试结果前冻结；不能看到结果后移动标准。
