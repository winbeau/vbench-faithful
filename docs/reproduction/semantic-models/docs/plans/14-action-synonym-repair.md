# Action 同义表达修复 v2

用户要求：Origin 保留原有同义表达大幅降分，Repair 对同一动作的表达变化保持稳定。复用固定 Action v9 final、冻结 UMT 缓存和已存在的 60 对同义契约，不修改官方评分、训练数据或视觉预测，不重新训练。

## 已定位原因

60 个同义输入中，旧链路 35 个成为 other；31 个原始模型输出非 other 动作短语，旧词表归一化未识别；4 个模型本身输出 other。故分别修复动作短语序列化、当前输入中已声明等价表达的确定性解析。原始模型 JSON 与旧结果保留。

## 固定实现范围

- 将首轮实验已经声明的同义词典移到生产可复用的模块，逐项核对内容/哈希不变；禁止从视频检测、变换标记、正确答案或原句预测复制目标或分数。
- Repair-model v2 明确表示 v9 模型加确定性接口，不声称纯 LoRA 重训收益或开放同义泛化。旧模型链路单列。
- 当前文本若完整匹配 K400 名称或声明的同义表达，可确定对应类别。支持规范的主语前缀、大小写、空白、冠词和并列；不能只匹配某个词就丢弃剩余未知动作。
- 先识别完整类别名，再拆分并列，避免拆坏 clean and jerk 等类别。否定、意图、观看动作等语境不能因含关键词被强配；同义碰撞保持未知。模型非法/缺失输出不能被规则悄悄转为完整成功。
- 未完全覆盖的开放文本保留模型解析路径与未知/歧义记录；other 记零，不把它当成同义稳定成功。完整别名覆盖域中的规则接管必须在每条结果中记录。
- 推理入口、缓存后处理、评分和表格使用同一个实现；提供 legacy-model 模式复现旧链路。新产物独立目录，保留 Spatial v2。

## 验收

1. 全部 60 同义家族、1,200 视频保持原始/同义目标集合和分数一致，Origin 逐项不变；统计全分母、家族 CI 和正确且一致率。
2. 类别替换确实改变当前目标；OOV 和已知＋OOV 不强配、不丢已知动作；所有 400 K400 原名正确序列化。
3. 扩充工程反例：否定、仅观看/意图、歧义、多动作、类别名含 and、词面相似但不同对象的 OOV、重复/空/非法输出；工程样本不充当独立盲测。
4. 比较旧后处理、仅输出短语归一化、加入当前输入完整覆盖的三种链路，披露覆盖域和规则贡献。
5. 完整四维回归确认 Origin、Spatial v2、Scene、Objects 不变；完整 pytest、CLI help、lock、diff check；报告代码/词表/输入/输出哈希及资源。

## 实际完成

生产推理、缓存重放和评分已共用接口。195 项测试通过，400 类原名全部往返一致；词典与 ea9d500 提交逐项相同。仅输出归一化将同义类别正确从 25/60 提到 51/60；加入完整当前输入契约后为 60/60，原始/同义均分 0.88917→0.88917，1,200/1,200 视频完全一致。Origin 仍为 0.88917→0。全矩阵 88,980 条中只有 6,000 条 Action Repair-model 进入新接口，其余 82,980 条与上一版本逐字段一致。详细限制、消融和复现见 [结果报告](../deterministic/action-repair-v2/README.md)。
