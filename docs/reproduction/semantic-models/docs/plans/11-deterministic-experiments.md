# 四维确定性（蜕变）实验设计

目标：不看人工偏好，用**确定性变换**制造"人类预期唯一"的输入，检验两条流水线是否按预期移动：
**Official**（VBench 原版评分）与 **Repair**（本项目四维语义适配器 + 同一视觉后端）。
每个变换都是一个 metamorphic relation（MR）：要么分数**必须显著变化**（敏感性半边），
要么**必须保持不变**（不变性半边）。两边都过，才说明指标"讲道理"。

沿用审计仓库既有约定：按 base 配对、按家族 bootstrap、报告配对 Δ 与 CI、预注册方向与阈值；
不使用 pooled CPA，不事后移动门槛。

## 0. 判据与打分口径

| 记号 | 含义 |
| --- | --- |
| `S_o(x)` | Official 后端对输入 `x` 的分数 |
| `S_r(x)` | Repair 后端（我们的解析结果 + 同一视觉后端）对 `x` 的分数 |
| `Δ_dim(x, T)` | 变换 `T` 前后该维度分数的配对变化 |
| 敏感性 | 期望 `Δ` 显著且方向正确（例如镜像后 spatial 分数必须大幅下降） |
| 不变性 | 期望 `|Δ|` 在预注册非劣界内（例如同义改写后分数不应下降） |
| 隔离性 | 变换目标维度时，**其他三个维度**的分数不得随之变化（`|Δ|` 在界内） |

每个 MR 先写清楚"人类预期"，再看数据；报告 pass/fail 比例与配对 Δ 的分布，而不是只报均值。

## 1. Spatial（spatial_relationship）

输入是 prompt 里的方位关系；视觉后端给出对象框，判据是几何方向。

| MR | 变换 | 人类预期 | 检验什么 |
| --- | --- | --- | --- |
| S-1 | 视频水平镜像 | 原 prompt 判据**翻转**：`left` 变 `right`。原 prompt 分数显著下降；把 prompt 中 left/right 互换后分数回到高位 | 后端是否真的用图像几何（而非仅文本） |
| S-2 | prompt 侧 left↔right 互换（视频不变） | 与 S-1 同向：分数显著下降 | 文本解析是否正确进入几何判据 |
| S-3 | 视频垂直翻转 | `above`↔`below` 互换，同上 | 上下方向 |
| S-4 | 同义改写（`left of` → `to the left of`，`above` → `on top of`） | **不变**：分数不得下降 | 文本归一化；Official 的字符串匹配在此最易失败 |
| S-5 | 恒等（无变换） | Δ≈0 | 流水线确定性 |

Repair 侧的预期收益集中在 S-4（归一化）与 S-1/S-2 的**方向一致性**（解析出有序三元组后再判几何）。
审计已指出 spatial 家族的族设计有问题（tie 判据饱和），因此本实验只报"方向是否翻转"和"同义是否稳定"，不引用旧 tie 结论。

## 2. Human Action（human_action）

| MR | 变换 | 人类预期 | 检验什么 |
| --- | --- | --- | --- |
| A-1 | 视频时序反转 | 动作不再成立（K400 top-5 应失去原类别），分数显著下降 | 后端是否依赖时序方向 |
| A-2 | 替换 prompt 动作为另一 K400 类（视频不变） | 分数显著下降（新类别不应出现在 top-5） | 文本解析是否真的换了类别条件 |
| A-3 | 同义改写（`riding a bike` → `riding a bicycle`；`playing guitar` → `playing the guitar`） | **不变**：分数不得下降 | 语义等价；Official 关键词匹配的薄弱点，Repair 的 K400 别名/规范化应对齐 |
| A-4 | 词表外动作（`assembling furniture`） | Repair 输出 `other`，按协议**不参与打分**或记为不支持；Official 无此概念 | B2 的 `other` 协议在评分端的落地 |
| A-5 | 恒等 | Δ≈0 | 确定性 |

## 3. Multiple Objects（multiple_objects）

| MR | 变换 | 人类预期 | 检验什么 |
| --- | --- | --- | --- |
| O-1 | occlusion-only ladder：逐级遮挡一个目标对象（不改变其他像素） | 该对象贡献单调下降；完全遮挡后**合取判据下总分→0** | 敏感性 + 单调性；沿用审计的 occlusion-only 设计 |
| O-2 | prompt 增加一个画面中不存在的对象 | 分数→0（硬合取） | 是否真的要求"全部出现" |
| O-3 | prompt 删除一个对象（视频不变） | **不变**（要求更少不应扣分） | 不变性；Official 的实现常在此出错 |
| O-4 | 同义/复数改写（`cat` → `cats`，`bicycle` → `bike`） | **不变** | B3 规范名与别名表 |
| O-5 | 恒等 | Δ≈0 | 确定性 |

## 4. Scene（scene）

| MR | 变换 | 人类预期 | 检验什么 |
| --- | --- | --- | --- |
| C-1 | 视频替换：用另一场景 prompt 生成的视频配原 prompt | 分数显著下降；Repair 应输出 `contradicted` | 场景是否真的看图 |
| C-2 | prompt 场景词替换（`ocean` → `forest`，视频不变） | 分数显著下降 | 文本条件是否生效 |
| C-3 | 同义改写（`beach` ↔ `seaside`，`ocean` ↔ `sea`） | **不变** | Tag2Text 关键词匹配最弱处；Repair 的三标签模型应对同义稳定 |
| C-4 | 去掉场景要求（prompt 只留动作/对象，视频不变） | Repair 输出 `insufficient`，**不判负**；Official 因无关键词而虚高 | B5 的 `insufficient` 协议 |
| C-5 | 恒等 | Δ≈0 | 确定性 |

C-3/C-4 是 Repair 相对 Official 最可能产生"确定性收益"的两处，也最容易写成人话解释给审稿人。

## 5. 数据与实现

- **基集**：沿用冻结资产，不新造评测集：`counterfactual-vbench`（H100，205 base / 815 派生片段，已发布）+ VBench 1.0 human-preference 视频（H100）。**只用 test 侧家族做报告**，dev 家族留给调试。
- **视频侧变换**：镜像/翻转（`ffmpeg hflip/vflip`）、时序反转（`reverse`）、遮挡（在目标框内贴中性色块，审计已有实现）、视频替换（按场景家族换源）。
- **prompt 侧变换**：文本层面的确定性改写脚本（互换方位词、替换动作/对象/场景词、同义替换表），全部落盘为 JSONL 并可审核。
- **两条流水线**：
  - Official：H100 上既有 VBench 评分环境（锁定 checkout `fd18b3d`）逐维度重算；
  - Repair：本项目 adapter 解析 prompt（`scripts/predict.py` / `inference.py`）+ 同一视觉后端判据；Scene 用独立模型 + 标签边界约束。
- **统计**：按 base 配对 Δ，按家族 bootstrap 95% CI，符号检验；敏感性半边与不变性半边**分开报**；同时报维度隔离性（例如镜像后 objects/scene 的 Δ）。
- **预注册**：每个 MR 的方向、非劣界（如 3 个百分点）、最小 base 数先落盘再跑，写入 `docs/plans/11-...` 附录。

## 6. 产出

1. `docs/deterministic-experiments-report.md`：每个 MR 的 pass/fail、Official vs Repair 配对 Δ 与 CI、失败样例（含视频帧与解析输出）。
2. 变换后的数据集清单（变换类型、base、seed、哈希），供复现与论文附录。
3. 结论口径：只声明"在该确定性变换下，Repair 是否比 Official 更符合人类预期"，不外推为整体质量提升。

## 7. 风险与反例

- 镜像会同时翻转画面中的文字与手性物体（左手/右手），需在报告里标注受影响 base 并做剔除敏感性分析。
- 遮挡块本身可能改变对象检测（非目标对象被牵连），必须做 O-1 的"非目标对象不变"对照。
- 时序反转对少数对称动作（如 `marching`）可能仍被识别，需在 A-1 中单列这些类别而不是当成失败。
- Official 的失败可能来自后端本身（检测/分类），Repair 无法修复视觉漏检；报告需把"文本接口错误"与"视觉后端错误"分开计数。
