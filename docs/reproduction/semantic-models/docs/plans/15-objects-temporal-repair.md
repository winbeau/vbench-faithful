# Objects 相邻帧确认修复 v2

用户要求继续优化 Objects Repair。现有文本解析在本轮 49 个输入上已经一致，残留问题在视觉检测：模型复核为目标全帧不可见的 275 视频中，29 个仍有正分，其中 14 个的合取正分只出现在孤立采样帧。此诊断已经查看测试结果，因此本轮属于公开的事后工程修复，不能称为独立盲测。

## 固定方案（在复算新方法效果前记录）

- 保留原模型、原始检测缓存、全部冻结清单、Origin 与旧版结果。
- Repair 使用当前视频的 16 帧检测框。每个当前帧中要求的实体，至少一个框必须在前一帧或后一帧得到同名框确认，IoU 固定为 **≥ 0.5**。边界只使用实际存在的相邻帧；不跨缺帧、不环绕、不补检测、不改变实体目标。
- 同一当前帧的全部要求仍为合取；只删除未经确认的正分，不将负分补为正分。孤立检测标为 **unconfirmed**，不是已证实对象不存在。未知/坏框保留缺失率；确认不足单列弃权率。
- 评分函数只接收实体列表和检测帧，不接收遮挡强度、遮挡位置、目标/背景变换名、可见性标签、参考答案或原视频配对分数。原始、背景遮挡、目标遮挡、非目标遮挡应用完全相同的函数。
- 同时对比“仅同名相邻帧”和“同名＋IoU 相邻帧”，不据本轮测试收益搜索阈值或选择最优参数。两者都是规则后端，不是 LoRA 学习收益。
- 完整保留 980 视频、12,740 条 Objects 清单项及未知端点。275 个模型复核端点、142 个隔离移除、背景匹配对照和模型标注仍可见的帧分别报告。模型复核不是人工金标。

## 验收与限制

1. 新正分只能是原检测合取正分的子集；零遮挡/恒等精确不变；时间反转和统一平移/缩放不改变确认结果。
2. 孤立误报减少，同时报告原始正分保留、所有 980 原始视频均分变化、背景对照与可见帧的变化，避免常数零评分冒充改善。以预先已有的 0.03 均分容差报告副作用，不按结果改阈值。
3. “无正分”与“全部明确拒绝”分开；unconfirmed 不能充当已验证阴性，也不能因缺帧而通过敏感性。
4. 四维全矩阵回归：只有 Objects 两个 Repair 允许变化，Origin 与 Spatial v2、Action v2、Scene 逐字段保持；legacy-official 模式重现上一版 Objects。
5. 工程反例、完整 pytest、CLI help、lock、diff 检查、来源及产物 SHA、表格和复现命令。

相邻采样帧并非独立检测器。持续幻觉、快速运动、短暂可见的真实对象及重复采样帧仍是限制；本方案不能保证消除所有误报。H100 GPU 4 预检时有既有高负载任务，本轮使用 CPU 复算，不启动新训练、视觉推理或付费 API。
