# 冒烟实施主计划：清洗 → 训练编码 → 最小闭环

状态：S1/S1.5/S2/S3 已实施，结果见[冒烟报告](../smoke-report.md)；正式数据与正式训练仍未开始。此计划细化P1/P2，不替代原始数据盘点及研究约束。

## 目标

用极小、可追溯的数据跑通两个模型系统：

- Scene独立模型：prompt + caption → supported/contradicted/insufficient单标签。
- 解析模型：prompt → JSON；一个冻结backbone、spatial/action/objects三个独立LoRA，按外部任务硬路由。

证明数据读取、loss、反传、adapter保存加载和推理接口正确；不把训练loss下降或训练集记忆视作泛化提升。

## 资源与停止边界

1. 默认不调用teacher API、不下载新媒体、不跑全量Tag2Text、不训练正式模型。S1.5 的 20 次授权已用满；再调用必须先取得新授权。
2. 数据检查使用现有标注；许可未明的Flickr仅盘点/隔离，不自动生成可训练发布集。
3. CPU测试随机初始化微型模型，不访问模型仓库。8B烟测需先确认模型SHA、本地权重路径和具体空闲GPU；尚未确认时只停在该门禁，不伪造运行成功。
4. 先单卡、一次一个任务，不kill现有进程，不抢占其他作业。优先48GB设备，无需默认申请H200。
5. 不升级锁、不修改原audit指标、不把MovieGen无标签数据自动转换成真值。
6. 本计划阶段不commit/push；后续执行时依据当轮授权处理。
