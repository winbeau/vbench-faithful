# P3：评测与后续集成

## 对照

旧规则、简单规范化、相同基模zero-shot、任务LoRA。评分规则改动与解析改动分别消融，尤其Action top-5和多对象扩展。

## 指标

| 任务 | 接口指标 |
| --- | --- |
| Spatial | 有序三元组集合F1、全句exact match、方向/主客体交换错误 |
| Action | K400映射准确率与macro-F1、词表外误映射率、多动作选择错误 |
| Objects | 对象集合precision/recall/F1、多对象遗漏率、错误别名映射 |
| Scene | 三类macro-F1、困难负例误接受率、不足率、真实场景天花板分析 |

共同报告schema有效率、失败与不支持覆盖、p50/p95延迟、吞吐、峰值显存。不通过静默过滤难例改分母。

## 泛化

同义改写、关系反转、非and枚举、相近动作/场景、未见组合。按源prompt/视频cluster bootstrap，不把同源帧作为独立样本。

## 端到端

先冻结视觉后端与评分公式，测纯语义接口改动。独立人工自然偏好集上报告分维度pairwise agreement、配对差值95% CI及coverage。挑战集改进不等于自然集提升。

Scene高分可能反映生成成功，不人为制造区分度；caption视觉幻觉与语义核验错误分开分析。

## 集成门禁

未验证真实权重/CUDA/完整训练时明确标注。所有集成先在新输出目录进行，不修改Official基线、冻结结果或旧论文表。研究claim严格限于已验证的语义接口，不宣称修复全部VBench缺陷。
